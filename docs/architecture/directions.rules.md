# ARCH directions — enforced rules

- **ARCH-DIRECTIONS-01** [decided] The directions step MUST run only when `create` is invoked with `--directions`, as an optional step before the build loop, with its procedure in `skills/create/references/directions.md`; it MUST NOT add a skill, an agent or a `commands/` entry (ARCH-PLUGIN-01/07/09), and `create` without the flag MUST behave exactly as today — check: `ls skills agents`; create SKILL.md names `--directions` only in an optional step that links directions.md; the Loop and Stop condition sections are unchanged — cite: docs/ideas/design-directions.md:124
- **ARCH-DIRECTIONS-02** [decided] Schools MUST be exactly the fixed ten ids `minimalist, swiss, material, flat, neumorphism, glassmorphism, brutalist, editorial, retro-futurist, aurora`, owned by an exported `SCHOOLS` constant in `scripts/directions.mjs` (with `ambitious: true` on `glassmorphism`, `retro-futurist`, `aurora`) and listed with their per-axis signatures in directions.md; user-defined schools MUST NOT be accepted — check: `directions.test.mjs` asserts the constant equals the ids in directions.md's table; an unknown `school` exits 2 — cite: docs/ideas/design-directions.md:128
- **ARCH-DIRECTIONS-03** [decided] A run MUST hold Current plus 3–5 directions with distinct schools, none equal to the current concept's school, and at least one ambitious school; directions MUST be written in-session as perspectives, never by dispatching agents, and the design-critic MUST NOT score directions (ARCH-PLUGIN-10/11 unchanged) — check: `directions.mjs` exits 2 on count, duplicate or missing-ambitious violations; directions.md contains no Agent/Task dispatch — cite: docs/ideas/design-directions.md:115
- **ARCH-DIRECTIONS-04** [decided] Current's token values MUST be read by `directions.mjs` from `docs/design/DESIGN.md` through `scripts/design-md.mjs` (format 2, else exit 2), never typed by the model; the named current concept is a judgement that MUST cite DESIGN.md rows or code `file:line` and MUST NOT be presented as a score (ARCH-VERIFY-18) — check: script imports design-md.mjs; directions.json has no Current token values; directions.md requires evidence for the concept — cite: scripts/design-md.mjs:1
- **ARCH-DIRECTIONS-05** [decided] `directions.json` MUST be `schema: 1` with, per direction, `id`, `school`, `brief` and the axes `palette`, `type`, `shape`, `motion`, `base`, each a map from a DESIGN.md token name (Semantic, Type scale, Spacing, Motion or Component token) to a value, or a new name marked `proposed: true`; every colour token MUST carry both `light` and `dark` values (ARCH-PLUGIN-35); `base` MUST hold only token-expressible values (spacing and component tokens), never markup or layout structure — check: schema tests exit 2 on a missing dark value, an unknown unproposed token or a non-token `base` key — cite: docs/architecture/plugin.rules.md:45
- **ARCH-DIRECTIONS-06** [decided] `scripts/directions.mjs --directions <json> --project <dir>` MUST write only `directions.html` and `fonts/` under `<project>/.artist/directions/<UTC-timestamp>/`, byte-identical for identical inputs, rendering every direction and Current on one fixed sample screen (sign-in form plus a small dashboard: nav, card, list, badges, primary and secondary buttons) defined in the script, never model-authored HTML; the page MUST offer the final-result view per direction, the specimen view with differences from Current highlighted, and pick & mix (one base direction, then palette, type, shape and motion from any direction) with a live preview beside Current, a light/dark switch, reduced-motion and reduced-transparency previews, and the live token diff and impact list; React Native projects are rendered as a labelled web approximation — check: test asserts written paths, determinism (two runs, same bytes) and the presence of each view — cite: docs/ideas/design-directions.md:117
- **ARCH-DIRECTIONS-07** [superseded by ARCH-DIRECTIONS-15]
- **ARCH-DIRECTIONS-08** [decided] `directions.mjs` MUST compute WCAG 2.x contrast for text, muted text, link and accent-text against their backgrounds and surfaces in light and dark for every direction and for the live mix; a pair under 4.5:1 MUST render a visible warning badge naming the pair and ratio, MUST NOT block rendering or picking, and MUST be carried into `pick.json` as `contrastWarnings`; the `create` stop condition (ARCH-PLUGIN-24) stays the gate — check: fixture with a 3:1 pair renders the badge and exits 0; ratios equal reference values to 2 dp — cite: docs/architecture/plugin.rules.md:34
- **ARCH-DIRECTIONS-09** [decided] The page MUST hand a pick back only as a copyable pick line `artist-pick v1 base=<id> palette=<id> type=<id> shape=<id> motion=<id>`; `directions.mjs --resolve "<line>" --directions <json> --project <dir>` MUST treat the line as untrusted, accept only ids present in that `directions.json` (else exit 2), and write `pick.json` (`schema: 1`: the pick, `tokenDiff{added,removed,changed}` in the `rounds.json` shape, `contrastWarnings`, `impact`, `wontCarry`) into the same run dir; no download or upload path is used — check: resolve tests for a valid line, an unknown id, extra keys and injected text — cite: skills/create/SKILL.md:77
- **ARCH-DIRECTIONS-10** [decided] A resolved pick MUST be applied project-wide as one token diff to the current theme (not a new `data-brand` set) by `design-system` after the user accepts it (ARCH-PLUGIN-14/38), and `create` MUST then build through the unchanged loop and stop condition, the ambitious school included — check: directions.md hands `pick.json` `tokenDiff` to design-system init step 8; no script or other skill writes DESIGN.md or token files — cite: skills/design-system/SKILL.md:34
- **ARCH-DIRECTIONS-11** [decided] The impact list MUST be computed by `directions.mjs` by joining `docs/design/inventory.json` `tokensUsed` and `usage` (read-only, schema unchanged per ARCH-VERIFY-23) to each changed token; "won't carry across" items MUST come only from a supplied `reuse.json` produced with `--all` (raw colours, spacing, motion, `component_token_literals`), and without one the section MUST say it was not checked and name `design-system audit` — check: tests for impact join, absent inventory (section says so, exit 0) and absent reuse.json — cite: scripts/inventory.mjs:356
- **ARCH-DIRECTIONS-12** [decided] Fonts MUST come from open-licence (OFL) woff2 files bundled under `scripts/assets/fonts/` and listed in `scripts/assets/fonts/fonts.json` (family, weights, source URL, version, sha256, licence file), at most two families per school, latin subset; the renderer MUST copy only the files a run uses into `<out>/fonts/` and reference them relatively; the project's current fonts load by relative path when a local font file is found through the Platform notes token files, else a fallback stack labelled with the intended family — check: test verifies every sha256 and licence file in the manifest; output references fonts only under `fonts/` — cite: docs/architecture/verify.rules.md:20
- **ARCH-DIRECTIONS-13** [decided] `scripts/directions*.test.mjs` MUST run under `node --test` (ARCH-VERIFY-11) and cover determinism, CSP and no-network, CSS-value rejection, contrast values, the SCHOOLS/directions.md match, resolve validation, the impact join and missing inputs; `evals/create/` MUST gain a `--directions` case (ARCH-PLUGIN-20) — check: test names; `ls evals/create` — cite: docs/architecture/verify.rules.md:21
- **ARCH-DIRECTIONS-14** [decided] Implementation MUST NOT start before `reuse-check.mjs` reports `component_token_literals` (ARCH-VERIFY-22; design-doc-uniformity units reuse-component and reuse-ratios) and that plan's `skill-create-optimise` unit has merged (met: `scripts/reuse-check.mjs:315`; Vue/Nuxt inventory merged at ff5018b); for a component format inventory does not parse (`.svelte`, `.astro`, `.marko`, `.riot`, found by a bounded walk of the project since inventory never lists them), the impact list MUST state that it is unsupported rather than show zero, and a walk that stops at its entry limit MUST say so the same way — check: the design-directions plan depends on those units; impact tests for an unsupported extension in inventory, for a `.svelte` file found in the project and for a truncated walk — cite: scripts/directions.mjs:479
- **ARCH-DIRECTIONS-15** [decided] (amends ARCH-DIRECTIONS-07: the grammar now lists the forms motion, type and shape tokens need) `directions.html` MUST be self-contained with no network requests (no `http:`/`https:` in `src`, `href` or `url()`), carry `<meta http-equiv="Content-Security-Policy" content="default-src 'none'; style-src 'unsafe-inline'; script-src 'unsafe-inline'; font-src 'self'; img-src 'self' data:">`, HTML-escape every value, and accept a CSS value only if every space- or comma-separated term matches a strict grammar — hex; `rgb()`/`rgba()`, `hsl()`/`hsla()`, `oklch()` with only numeric arguments; linear/radial gradients of those with `deg` angles and `%` stops; numbers bare or with `px`, `rem`, `em`, `ms`, `%`; `cubic-bezier()`; the keywords `ease`, `ease-in`, `ease-out`, `ease-in-out`, `linear`, `inset`; and font families from the font manifest — and MUST reject any value containing `;`, `{`, `}`, `<`, `>`, `\`, quotes, backticks, `url(`, `expression(`, `/*` or `@import`, or longer than 200 characters, exiting 2; its inline script MUST only switch between precomputed values (no `eval`, `Function`, `innerHTML` from data) — check: test greps output for external URLs and the CSP meta; fixtures with `;`, `}`, `url(` or `expression(` in a value exit 2; the grammar test accepts the documented shapes and rejects non-numeric colour arguments and non-`deg` hue units — cite: scripts/directions.mjs:52
