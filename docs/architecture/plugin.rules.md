# ARCH plugin — enforced rules

- **ARCH-PLUGIN-01** [decided] MUST expose every user-invocable entry as a skill under `skills/<name>/SKILL.md`; MUST NOT add a `commands/` directory — check: no `commands/` dir and no `commands` key in plugin.json — cite: docs/ideas/artist-ui-plugin.md:101 (plugins-reference: prefer skills/)
- **ARCH-PLUGIN-02** [decided] MUST NOT ship hooks in v1 (no `hooks/` dir, no `hooks` key) — check: absence in tree and plugin.json — cite: docs/ideas/artist-ui-plugin.md:186 (craftsman hooks/hooks.json L8-24)
- **ARCH-PLUGIN-03** [decided] MUST NOT declare a `dependencies` entry on craftsman or require craftsman to be installed — check: plugin.json `dependencies` absent or craftsman-free; skills work when no craftsman.config.json exists — cite: docs/ideas/artist-ui-plugin.md:30
- **ARCH-PLUGIN-04** [decided] MUST bundle at most two MCP servers, `playwright` (`@playwright/mcp@0.0.83`) and `chrome-devtools` (`chrome-devtools-mcp@1.12.0`), each pinned to an exact version; MUST NOT use `@latest` or a range — check: `.mcp.json` has ≤2 servers and every npx arg ends in `@<x.y.z>` — cite: docs/ideas/artist-ui-plugin.md:193
- **ARCH-PLUGIN-05** [decided] `chrome-devtools` MUST run with `--no-usage-statistics --isolated --headless`; `playwright` MUST run with `--isolated --headless` — check: args in `.mcp.json` — cite: docs/architecture/plugin.rules.md:15 (chrome-devtools-mcp README: data collection on by default)
- **ARCH-PLUGIN-06** [decided] MUST NOT place credentials in `.mcp.json` or any skill; opt-in servers needing keys MUST take them from `userConfig` options marked `sensitive: true` — check: grep for key-shaped literals; every key option has `sensitive: true` — cite: docs/ideas/artist-ui-plugin.md:76 (plugins-reference: userConfig sensitive)
- **ARCH-PLUGIN-07** [decided] Workflow skills MUST be exactly `design-system`, `create`, `verify`, `optimise`; platform knowledge MUST live in on-demand reference packs `skills/create/references/web.md` and `skills/create/references/mobile.md`, not in SKILL.md bodies — check: `ls skills/`; SKILL.md files reference, not inline, platform detail — cite: docs/ideas/artist-ui-plugin.md:197 (craftsman EXTENDING.md L246-258)
- **ARCH-PLUGIN-08** [decided] Each `SKILL.md` MUST stay under 500 lines and carry a one-sentence `description` — check: `wc -l skills/*/SKILL.md` — cite: docs/ideas/artist-ui-plugin.md:197 (craftsman EXTENDING.md L252)
- **ARCH-PLUGIN-09** [decided] The only agent MUST be `agents/design-critic.md` with tools limited to `Read, Glob` (no Edit, Write, Bash, or network tools) — check: frontmatter `tools:` line — cite: docs/ideas/artist-ui-plugin.md:61 (craftsman agent-mode-guard.mjs L101-102)
- **ARCH-PLUGIN-10** [decided] `create` MUST dispatch `artist:design-critic` at most once per refine round and never in parallel; on a blocked or failed dispatch it MUST run the critic brief itself and label the round `NOT ISOLATED` — check: create SKILL.md loop text — cite: docs/ideas/artist-ui-plugin.md:61 (craftsman agent-mode-guard.mjs L93-128)
- **ARCH-PLUGIN-11** [decided] The critic brief MUST contain only the screenshots, `report.json`, `DESIGN.md` and the rubric — never the builder's reasoning or the user's pitch — check: create SKILL.md dispatch section — cite: docs/ideas/artist-ui-plugin.md:148
