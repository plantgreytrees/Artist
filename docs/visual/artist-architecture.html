Blueprint · artist-ui-plugin

Artist: a UI plugin that renders, scores and refines its own work

Artist is a separate Claude Code plugin for web (React, Next.js, Tailwind) and mobile (Expo, React Native). Using frontend-design and Playwright on their own gave decent results. Artist adds three things to get to great: a project design system in docs/design/DESIGN.md, an isolated critic that scores screenshots against an eight-point rubric, and measured accessibility and Core Web Vitals. It loops up to three rounds until every check passes.
