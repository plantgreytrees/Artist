# Design system

Written only by the `design-system` skill. `reuse-check.mjs` and `inventory.mjs` parse this file, so keep the section names and table headers exactly as shown. Components, Layouts, Schemas and Packages between the markers are generated by `scripts/inventory.mjs`; never edit them by hand.

## Semantic tokens

Components use these through the CSS variable (or theme key), never the primitive or a literal.

| name | variable | primitive | use |
| --- | --- | --- | --- |
| color.action.primary | --color-action-primary | blue.600 | primary actions, links |
| color.surface.page | --color-surface-page | gray.50 | page background |
| color.text.body | --color-text-body | gray.900 | body text |
| radius.card | --radius-card | radius.md | cards and panels |

## Themes

One set per brand, each with light and dark values for every semantic token. Adding a brand means adding a theme set here and in the theme file, never new literals in components.

| brand | token | light | dark |
| --- | --- | --- | --- |
| default | color.action.primary | blue.600 | blue.400 |
| default | color.surface.page | gray.50 | gray.900 |
| default | color.text.body | gray.900 | gray.50 |

## Motion

Every animation uses these tokens and has a reduced-motion fallback (`prefers-reduced-motion`, `motion-safe:` / `motion-reduce:`, `useReducedMotion`).

| name | value | variable | use |
| --- | --- | --- | --- |
| motion.duration.fast | 150ms | --duration-fast | hover and focus feedback |
| motion.duration.base | 300ms | --duration-base | panels and dialogs |
